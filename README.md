# Cobra Chess AI 🐍♟️

A custom Python chess game and Minimax AI engine built using Pygame and `python-chess`.

## Features
- **Cobra AI:** Minimax search algorithm with Alpha-Beta Pruning.
- **Interactive Board:** Full board coordinates (a1–h8), legal move hints, red check indicators, and customizable UI.
- **Controls:** Resizable/fullscreen window (F11), Move Undo, Hint generator, and Resign options.
